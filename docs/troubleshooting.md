# Troubleshooting

Use `docker compose ps` and redacted `docker compose logs --since 10m gateway tts-ema stt-whisper`. Never paste API keys, recordings, caller identities, or transcripts into an issue. Base file audio must work without n8n/telephony.

| Symptom | Investigate / action |
| --- | --- |
| Compose config says a required variable is missing | Nothing is required any more: the one-shot `secrets` service generates the keys and the keyring on first `up -d`. Only populate `.env` to pin your own distinct `VOXI_API_KEY` / `VOXI_WORKER_API_KEY` (each at least 32 characters). There are deliberately no committed secrets. |
| `secrets` refuses to start | It only refuses for TLS in strict mode: `REQUIRE_PROVIDED_CERTS=1` with `certs/voxi.crt` + `certs/voxi.key` missing, or with a certificate carrying `certs/.generated-by-voxi`. Provide your own pair (or unset the flag to allow a generated loopback certificate). |
| `provision-*` fails and `up` aborts ("dependency failed to start") | Read the real cause from the job's own log: `docker compose logs provision-ema` (or `-whisper` / `-whisper-turbo` / `-antalia`). The first install needs internet: a network/DNS error is reported as "Cannot reach Hugging Face" (check connectivity/proxy, then re-run — finished files are kept), HTTP 429/5xx is rate limiting or a transient outage (wait and re-run the same provision service; nothing downloads twice), and HTTP 401/403 means the repository is gated (pass a read-scoped token as `HF_TOKEN`; all pinned repos are public today, so this is not needed for the defaults). Inside a corporate proxy set `HTTPS_PROXY` for the job. Runtime workers never download at startup, so once a model volume holds verified assets, no network is needed again. |
| Docker daemon/pipe unavailable on Windows | Start Docker Desktop, enable Linux/WSL2 containers, inspect `docker info`. No application workaround can replace a running engine. |
| Docker Hub `production.cloudfront.docker.com` DNS failure | This host could pull the byte-identical pinned Python image from `mirror.gcr.io`. Use the pinned-mirror build command below; do not replace the digest or disable TLS verification. Repair host/Docker DNS for normal Docker Hub access. |
| STT import fails with `No module named pkg_resources` | CTranslate2 4.6.0 requires this setuptools module. `.[stt]` explicitly pins `setuptools==80.3.1`; sync the lock/build the current image instead of suppressing import failures or installing latest setuptools. |
| Host Python reports missing standard-library `difflib` | Observed incomplete managed Python installation. `uv python install 3.12.12` restored the standard library here. Use complete Python 3.12; this is not an application dependency to install from PyPI. |
| Host dotenv parser rejects Windows model paths | Use forward-slash absolute paths (`C:/.../models/ema-lightning`) or properly quoted/escaped dotenv strings. Backslashes can be interpreted as escapes. Compose's Linux paths are unaffected. |
| Worker exits with missing model/manifest/integrity error | Build worker image, explicitly run its provision service, then `--verify-only` (commands in deployment guide). Workers intentionally do not download models at startup. Preserve corrupt artifact evidence; reprovision deliberately. |
| Model volume permission denied | Containers/provisioners use UID/GID10001. Newly created named volumes copy owned `/models` from image. A pre-existing root-owned bind mount/volume needs an operator-approved ownership repair or migration; do not run the worker permanently as root. |
| Health is healthy but readiness is not | `/healthz` means process liveness only. `/readyz` requires loaded/prewarmed model(s). Core services have 300s health grace; `up --wait` allows 600s. Inspect startup traceback, CPU/RAM, cache integrity and configured model paths, not an invented readiness response. |
| Gateway waits indefinitely for core dependency | Inspect each worker health/error, missing provision, and resource usage. `depends_on: service_healthy` does not provision models. Provisioning is automatic now: `up -d` runs the `provision-*` one-shot services and each worker waits for its own (`service_completed_successfully`). To provision or re-verify by hand, use `run --rm --no-deps provision-*`. |
| EMA writes fail with read-only filesystem | `/models` should remain read-only. Native batch-size/cache scratch belongs under `XDG_CACHE_HOME=/tmp/cache`; `/tmp` is writable tmpfs. Ensure cache override did not point at `/models` or image root. |
| 401/403 from public audio | Use audio key, `Authorization: Bearer <key>`, never worker/n8n secret. For scoped hashed keys, confirm `audio:read` (models) and `audio:write` (speech/transcription). |
| 401 between gateway and worker | Match `VOXI_WORKER_API_KEY` across gateway/workers; recreate all after rotation. Without `.env`, the one-shot `secrets` service generates it once into the `voxi-secrets` volume and never overwrites it. Network reachability does not bypass internal bearer auth. Never expose worker ports. |
| 429 at capacity / rate limit | Worker keeps a slot until real inference thread finishes, including timeout/cancellation. Slow CPU jobs can outlive client timeout. Wait for capacity; measure workload before increasing threads/slots/processes. Multiple Uvicorn workers duplicate models. |
| 413 or over-duration upload | Default file limit 25 MiB, duration 600s; whole multipart request also has a body limit, so leave room for multipart overhead. n8n webhook defaults to 16MB. Use shorter actual audio or intentionally align documented limits, not bypass validation. |
| 422 unsupported parameter/model/voice | Inspect OpenAI-style error. Physical voices are `ema-tr` and optional `antalia-tr`; no expressive/clone voices are fabricated. WAV/PCM/MP3 only; raw PCM has no container header. No SSML/instructions/realtime compatibility implied. `alloy` is opt-in compatibility alias only, not another speaker. |
| MP3 fails / smoke cannot decode | Container encoder requires FFmpeg. Host smoke also needs `ffmpeg` and `ffprobe` on PATH. Inspect actual Content-Type and FFmpeg stderr; do not treat JSON error bytes as audio or rename WAV to MP3. |
| Empty/inaccurate transcription | Validate actual decoded audio, duration, levels, language hint, and Turkish intelligibility. Smoke only requires an observed nonempty transcript, not a hardcoded sentence. Whisper small is a CPU default, not an accuracy promise; evaluate a larger provisioned multilingual model before changing defaults. |
| Antalia absent from `/v1/models` | Both opt-ins required: provision/start `--profile antalia` worker **and** set `ANTALIA_URL=http://tts-antalia:8083`, then recreate gateway. Keep EMA default. |
| Optional Antalia makes readiness fail | A configured provider is real dependency, not pretend available. Inspect its warmup/cache/device error or deliberately remove `ANTALIA_URL` and recreate gateway to disable it; do not suppress readiness failure. |
| CUDA `libcublas`/`libcudnn` or initialization failure | Use NVIDIA override, compatible CUDA12.6 host driver and Container Toolkit. CTranslate2 4.6.0 needs CUDA12/cuDNN9; override supplies torch2.7.0 cu126 wheel libraries matching the lock and LD_LIBRARY_PATH. Do not combine cuDNN8 or assume a CPU image includes CUDA. |
| GPU out of memory | EMA/STT/optional Antalia may reserve/share one GPU. Measure aggregate VRAM and concurrency; stop optional workloads or choose appropriately sized provisioned models. No hidden CPU fallback is promised. |
| OpenWebUI ignores env | Stored admin settings can take precedence. Update Admin Settings → Audio or deliberately disable persistent config; restart. Point Docker client at `gateway:8080/v1` on shared network, not its own `localhost`. |
| Hermes contacts cloud or sends unsupported Opus/instructions | Explicitly select both audio providers `openai` with local `stt.openai.base_url` / `tts.openai.base_url` and Voxi secret. Prefer MP3/WAV file mode; voice-bubble targets may request unsupported Opus. See Hermes guide. |
| n8n turn returns fallback | Verify production webhook published, Header Auth value `Bearer <VOXI_N8N_API_KEY>`, fixed reachable URL, timeout, response schema/idempotency key. No redirects or arbitrary caller-controlled URLs. One bounded attempt currently; fallback is an action, not actual playback/phone transfer. |
| n8n turns are stale/rejected | Latest-generation rule rejects late response from old utterance. Validate positive integer generation/sequence and `idempotency_key=call_id:turn_id`. n8n owns decisions; do not add gateway LLM rules to mask workflow failures. |
| n8n file STT has no binary `audio` | Example webhook accepts raw WAV body with `Content-Type: audio/wav`, not multipart. HTTP Request node sends proper multipart to Voxi. Select real credentials after import; no embedded credentials exist. |
| Offline override cannot reach n8n | Expected: internal speech network blocks external routing. Core file audio remains independent. If agent decisions are needed offline, deploy n8n on an explicitly approved local shared network and test it separately. |
| Phone call, RTP or real transfer unavailable | Barge-in, VAD turn detection and streaming synthesis/transcription exist only over Voxi's own WebSocket transports (ADR 0005). The deployment deliberately contains no SIP/RTP media runtime. Follow UCM6510 lab checklist; do not claim phone support from an HTTP action or a WebSocket frame, and do not add a fake service. |
| WebSocket handshake refused with HTTP 403 | The upgrade never completes: credentials missing or invalid, the key lacks the required scope (`audio:write` for `/v1/tts/stream` and `/v1/realtime/transcriptions`, `realtime:connect` for the session stream), the per-key `VOXI_RATE_LIMIT_PER_MINUTE` connection budget was hit, or all `VOXI_MAX_CONCURRENCY` sockets are already busy. The gateway closes before `accept()`, so a real ASGI server answers the handshake with HTTP 403 (`websockets` raises `InvalidStatus`), not a close code. Realtime clients that cannot set headers may pass `?token=` or `?api_key=`. Never paste the token into logs or issues. |
| WebSocket closes with 1008/1013/1011/1000 after connecting | These are post-accept close codes only: `1008` invalid opening frame, `1013` a transcription socket crossed its per-socket audio budget (10 minutes), `1011` internal transport failure, `1000` hangup, idle TTL or normal completion. Reconnect later; raise the audio budget only after measuring capacity, never to keep a broken client connected. |
| WebSocket upgrade returns HTTP 404/400 while REST works | The serving stack has no WebSocket implementation. uvicorn requires `websockets` (pinned) or `wsproto`; a bare uvicorn install serves REST silently but refuses every `/v1/*/stream` upgrade, and `TestClient` tests stay green because they bypass the ASGI server. Install the pinned dependency (or `uvicorn[standard]`), then verify with `python scripts/smoke_stream.py`. |
| Browser/LAN client gets **421 Misdirected Request** from the proxy | In injected mode the TLS proxy rejects a foreign `Host` before touching the gateway (the DNS-rebinding cut): the [`$host` allowlist](../integrations/nginx/README.md) matched nothing. Dial the loopback/LAN address the proxy is actually published on; on a deliberately trusted LAN add the host via `VOXI_ALLOW_LAN_INJECT=true` + `VOXI_PROXY_EXTRA_HOSTS`. Do not lower this guard for a public address — that is rebinding protection, not a name-server bug. |
| Browser gets **403** with a valid key | Cross-site guard: the request carries an `Origin`/`Sec-Fetch-Site: cross-site`. The studio is only meant to be same-origin with `/ui/`; a page served from another origin cannot legitimately call this API. An empty `Origin` (curl, OpenWebUI server-side) is allowed. |
| Proxy refuses to start: `VOXI_PROXY_INJECT=true but VOXI_PROXY_BIND_IP=... is not loopback` | Deliberate fail-closed invariant, `.env` edits cannot bypass it (the entrypoint re-checks at container start). Either per-client-key mode (`VOXI_PROXY_INJECT=false`, all bring-your-own-key) or a consciously trusted LAN with `VOXI_ALLOW_LAN_INJECT=true` + every legit host in `VOXI_PROXY_EXTRA_HOSTS` (invalid entries also refuse to start — they are interpolated into nginx `map` blocks and a malformed token is treated as a config-injection attempt). |
| A LAN install serves keyless requests although you expected to enter keys | `/ui/runtime.json` says `mode: "lan-inject"`: someone set `VOXI_ALLOW_LAN_INJECT=true`. Reverting: unset it (and empty `VOXI_PROXY_EXTRA_HOSTS`), recreate `proxy`. |
| `/ui/` loads but no asset/index script after a frontend rebuild | The WebUI bundle hash changes with every build. The proxy's read-only bind mount of `webui/dist` does not survive the wipe-and-recreate of Vite's output: `docker compose -f compose.yaml -f infra/compose.proxy.yaml up -d --force-recreate --no-deps webui && docker compose -f compose.yaml -f infra/compose.proxy.yaml restart proxy` (the recreate is what breaks the proxy's upstream; that is why the restart must follow). |
| Portal charges a different service on the mapped port | The composes publish only the proxy on `${VOXI_PROXY_PORT:-8443}`. Change the FREE host port via `VOXI_PROXY_PORT`; the container port stays 8443. |
| Stack peers cannot resolve `voxi-gateway` by name | Fixed `container_name`s (`infra/compose.lan-stack.example.yaml`) resolve only between containers on the SAME user-defined network: `VOXI_JOIN_NETWORK` must name an existing Docker network the OpenWebUI/n8n container itself is attached to and be set to `external: true`. Service aliases (`gateway`) work on the same network as well. |
| Host-bound models (VOXI_MODELS_DIR) permission denied | The stack-merge example mounts a host tree; model containers run as UID/GID 10001. `mkdir -p "$VOXI_MODELS_DIR" && chown -R 10001:10001 "$(dirname "$VOXI_MODELS_DIR")"`; do not run the worker as root to "fix" it. |
| Stream stops early with `cancelled` or never ends | `cancelled` is a client cancel or an idle TTL eviction (`VOXI_WS_IDLE_TIMEOUT`). Native kernels are only preempted at chunk boundaries, so a long chunk delays the stop. Check `VOXI_TTS_CHUNK_MS` and whether the consumer keeps reading: the bounded outbox deliberately applies backpressure instead of buffering forever. |
| Audio sounds wrong-pitched, garbled or too fast/slow | Streamed audio is headerless PCM16 mono at the rate declared in the `meta`/`session.started` event, not the file API default of 24 kHz. Read `sample_rate` from the handshake and configure the playback device accordingly; `?sample_rate=8000|16000` selects the session-stream inbound rate. |
| No turn fires from caller voice, or turns end too late | Energy VAD, not a model, owns endpointing. Inspect `speech_started`/`speech_ended`/`rejected_ms` events first. Adjust `VOXI_VAD_OPEN_RMS`/`VOXI_VAD_CLOSE_RMS` for the actual signal level, `VOXI_VAD_START_MS` for false triggers, `VOXI_VAD_END_MS` for endpoint patience and `VOXI_VAD_MIN_SPEECH_MS` for false-start suppression. Defaults are uncalibrated against real telephony audio. Clients with their own VAD may still send explicit `turn`/`barge_in` frames. |
| Transcription is empty or late during a realtime session | Partial and final results are whole-window STT worker calls, so a single-occupancy worker serializes them; `utterance_too_long`, `worker_failure` or transcription error events explain the rest. Check the worker's `/readyz`, `VOXI_STREAM_STT_TIMEOUT` and the declared sample rate before assuming model inaccuracy. |

## Evidence to attach

Record sanitized service version/image digest, model verification result, relevant error code, CPU/GPU/driver, audio format/duration (not sensitive content), and exact request shape. Separate model-free unit/contract results from live model smoke, UI client import/runtime results, WAN-denial proof, NVIDIA and real-PBX acceptance. A successful WAV download does not establish Turkish quality, streaming latency, three-call capacity, transfer interoperability, or licensing clearance.

## Pinned registry mirror

Same Python manifest digest, different download registry:

```sh
docker compose build \
  --build-arg PYTHON_IMAGE=mirror.gcr.io/library/python:3.12.12-slim-bookworm@sha256:593bd06efe90efa80dc4eee3948be7c0fde4134606dd40d8dd8dbcade98e669c \
  gateway tts-ema stt-whisper
```

Add `--profile antalia` before `build` and `tts-antalia` after service names for the optional worker. This changes only image retrieval location, not base-image content or inference providers. A mirror build is not proof of NVIDIA support.
