# Initial threat model

Protected assets: speech data, API/worker/webhook credentials, model files, session identities and future PBX access. Untrusted inputs: HTTP bodies, media containers, WebSocket control frames, inbound PCM16 microphone/telephony audio, STT transcripts and n8n action JSON.

Controls: localhost published gateway; no worker published ports; non-root read-only containers; fixed service URLs; independent internal bearer key; SHA256 application key hashes in memory/config with scope checks; bounded upload/text/duration/admission; no waiting GPU queue; request IDs without speech-text logs; trusted decoder subprocess; no redirect following; n8n response size/deadline limit; caller identity redacted; session owner isolation; cancellation generation checks; exact transfer-target allowlist; per-key concurrent socket cap plus handshake rate limit; WebSocket idle TTL; per-socket inbound audio budget; strict extra-forbid validation of every control frame and every outbound event. No recordings or persistent transcripts by default. Secrets are environment inputs or root-owned files written once by the one-shot `secrets` service — never committed credentials, and never printed, logged, or passed through a container environment when generated.

Deployment boundary: local Docker environment administrators can inspect environment secrets and read the `voxi-secrets` volume. For shared/production deployments use a secret manager, TLS termination, protected key files and host firewall. The default install generates a **loopback self-signed** certificate: it encrypts the transport but proves no server identity to a client, so trust still has to come from the client's own configuration. Set `REQUIRE_PROVIDED_CERTS=1` to refuse generated material and require an operator-supplied pair (a certificate this project generated is marked with `certs/.generated-by-voxi` and is refused in that mode). `VOXI_API_KEYS_JSON` stores only key hashes; secret rotation/revocation requires config reload/restart in this milestone. Raw application/worker/webhook secrets are not written to a database.

n8n destinations are administrator-controlled and fixed; use dedicated least-privilege webhook authentication. Do not configure public URLs if locality required. No user-controlled outbound fetch or freeform phone dialing. A malicious n8n workflow can still choose spoken content; gateway validates transport policy, not business truth. In future phone deployment enforce VLAN/source IP ACLs and a PBX dial plan; do not enable DISA/unrestricted Dial Trunk. Existing worker timeouts do not forcibly kill a stuck native thread: capacity remains occupied until work exits; process restart is required for hung native inference.

Realtime transport exposure (ADR 0005). WebSockets are long-lived, so they change the DoS surface rather than the trust model: an authenticated caller can hold one of the per-key concurrent sockets open until the idle TTL reaps it, and each held socket keeps its own bounded state — an energy-VAD utterance capped by `max_utterance_ms`, a 10-second unconsumed inbound buffer on the session stream, and a 10-minute total audio budget on the transcription socket. Outbound queues are bounded, so a client that stops reading applies backpressure to its own synthesis instead of growing gateway memory without limit. Inbound PCM is never written to disk by the gateway: it is analysed in memory, wrapped in an in-memory RIFF header and posted only to the fixed internal worker over the separate bearer key, where the existing seekable-decode temp-file rules below still apply. Only control frames are parsed, always through strict extra-forbid models, and every server event is validated before send, so a peer cannot negotiate an undocumented action or playout behaviour; the decision to speak, transfer or hang up still comes exclusively from n8n. Residual risk that remains open: one adversarial but valid `speak` request can occupy the single TTS inference slot for the full synthesis duration because a native kernel is only preempted at chunk boundaries, and a very large inbound WebSocket frame is buffered by the ASGI server before gateway code can inspect it. Prefer the `Authorization: Bearer` handshake; the `?token=`/`?api_key=` query fallback exists only for peers that cannot set headers and leaks credentials into any proxy or access log that records URLs.

Remaining release gates: decoder/dependency vulnerabilities, immutable image digests, scan/SBOM, TLS LAN access, offline WAN-block test, denial-of-service load (including sustained concurrent WebSocket sessions), real telephony toll-fraud review and Turkish privacy/legal review.

Decode input is spooled to a private, byte-bounded temporary file for seekability and deleted on completion/error. This is ephemeral processing, not retained call recording. A fixed audio-demuxer allowlist excludes playlist loaders; local file protocol is used only for that seekable input, with MOV external tracks/absolute aliases disabled by the audited FFmpeg defaults. Network protocols remain disallowed. Runtime `/tmp` is per-container tmpfs, not a persistent recording volume.
