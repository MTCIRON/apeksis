# Architecture

See ADRs for decisions. HTTP gateway -> fixed internal TTS/STT workers. Models cached and warmed before readiness. Failures return bounded OpenAI-style errors. Worker admission has no waiting GPU queue. Bearer secrets protect internal inference even on private Docker network. n8n turn adapter holds independent cancellation generations per session, authenticates fixed webhook requests and rejects stale results. No LLM prompt, memory or business rules inside gateway.

First milestone delivers file audio and independently usable n8n turn delivery primitives. A bounded WebSocket layer now adds near-real-time transport: an energy endpointer segments inbound PCM16, sustained caller voice barges into generation-tagged playout, the completed utterance is WAV-wrapped and transcribed by the STT worker, and the transcript is handed to n8n, which remains the only decision runtime. Two platform-specific sockets expose streaming synthesis and windowed transcription. Telephone/SIP/RTP media, DTMF and real transfer execution remain out of scope (ADR 0002) and no gateway-side LLM, prompt or business rule exists. PostgreSQL/Redis are unnecessary for stateless file APIs and short-lived media sessions; persistent multi-tenant administration is deferred.
